# GeneBlend Explorer

Build GeneBlend Studio as the polished, responsive interactive educational genetics simulator described in the user’s complete prompt. Implement the core landing page, lab with two parent trait builders, scientifically framed simplified genetics engine including accurate ABO blood-type inheritance, DNA mixing experience with skip/reduced-motion support, results, genetic details, Punnett square, comparison, learning content, FAQ/glossary, local persistence, reset/save/share affordances, sound toggle off by default, and full accessibility/responsive polish. Clearly show the educational-simulation disclaimer throughout.
